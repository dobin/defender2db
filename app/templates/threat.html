Static file signatures {{ threat.static_signatures|length }}

A static signature is a known-file fingerprint: a file size plus three partial CRC32 windows and one strong file hash. A prefix match only fingerprints the first N bytes and accepts any file that is at least that large; an exact size record requires the file length to match exactly. What do these values mean?

How to read flags and window values
  • File size — N, the number of bytes covered by the fingerprint.
  • Prefix match / Exact size — whether the actual file may be larger than N.
  • Partial CRC 1 — CRC32 of the first 4 KiB (zero-padded for short files).
  • Partial CRC 2 — CRC32 of the first min(N, 64 KiB) bytes.
  • Partial CRC 3 — CRC32 of the last 4 KiB of the N-byte prefix.
  • Flags — bit 0x0001 is the prefix-match bit; bits 12–14 select the strong hash: 0x0000 MD5, 0x1000 SHA-1, 0x2000 CRC32, 0x3000 SHA-1 (first 4 bytes), 0x4000 SHA-256.

Examples: 0x2000 = CRC32 with exact size; 0x2001 = CRC32 with prefix match.
